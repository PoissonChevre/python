# CS50's Introduction to Programming with Python — Harvard

[Course page](https://www.edx.org/learn/python/harvard-university-cs50-s-introduction-to-programming-with-python) · **Instructor:** David J. Malan · **Status:** in progress

## About

Harvard's CS50P teaches how to read and write Python code. Each week has a lecture and a problem set, checked against automated tests.

I write the problem sets in the CS50 codespace ([cs50.dev](https://cs50.dev)) and check them with `check50`.

**Length:** 10 lectures · 9 problem sets · 1 final project

## Course content

| # | Lecture | Topics |
|---|---|---|
| 0 | Functions, Variables | `print`, `input`, strings, numbers, my own functions |
| 1 | Conditionals | `if`, `elif`, `else`, `match` |
| 2 | Loops | `while`, `for`, lists, dictionaries |
| 3 | Exceptions | `try`, `except`, `raise` |
| 4 | Libraries | Modules, `pip`, APIs with `requests` |
| 5 | Unit Tests | `pytest` |
| 6 | File I/O | Files, CSV, images |
| 7 | Regular Expressions | `re` |
| 8 | Object-Oriented Programming | Classes, objects |
| 9 | Et Cetera | Type hints, `argparse`, comprehensions, generators |
| – | Final Project | A program of my own design |
