# [CS50's Introduction to Programming with Python – Harvard](https://www.edx.org/learn/python/harvard-university-cs50-s-introduction-to-programming-with-python)

Learn to read and write Python code, with weekly problem sets checked against automated tests

## About this course

Harvard's CS50P is an introduction to programming with Python, and part of my learning path in automation. All problem sets are written in the CS50 codespace ([cs50.dev](https://cs50.dev)) and checked with `check50`.

[Python Standard Library](https://docs.python.org/3/library/)

## Course Sections

10 lectures • 9 problem sets • 1 final project

0. **Functions, Variables**
1. **Conditionals**
2. **Loops**
3. **Exceptions**
4. **Libraries** – modules, `pip`, APIs with `requests`
5. **Unit Tests** – `pytest`
6. **File I/O** – files, CSV, images
7. **Regular Expressions** – `re`
8. **Object-Oriented Programming**
9. **Et Cetera** – type hints, `argparse`, comprehensions, generators

**Final Project** – a program of my own design
